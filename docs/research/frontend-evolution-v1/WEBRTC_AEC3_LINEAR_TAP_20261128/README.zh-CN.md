# F07：AEC3 线性输出与最终输出实际观察结果

实验：`FE04-WEBRTC-AEC3-LINEAR-TAP-V1`。执行日：2026-11-28（北京时间）。
跟踪：[#975](https://github.com/jiying2007/audio-pipeline/issues/975)，
实现与结果 PR：[#976](https://github.com/jiying2007/audio-pipeline/pull/976)，长期父研究：[#657](https://github.com/jiying2007/audio-pipeline/issues/657)。

## 结论与适用范围

**冻结的唯一主比较得到 `SUPPORTED_IN_DISCLOSED_WINDOW`；全研究处置保持
`DIAGNOSTIC_DIRECTION_ONLY_NO_PROMOTION`。**
在 `p1-ula4-70-fir33-none` 的 `double-before` 窗口内，线性导出比最终输出保留了更多与目标近端一致的信息，
且幅度敏感误差更小。最终输出在全部六个固定远端单讲区间的聚合回声／输出能量比都更高；
因此本结果同时保留近端保真与远端抑制之间的权衡。

本次实际执行只有一次六例，96 秒输入、9600 帧；六个最终 PCM 均与原封存 AEC3 最终输出逐字节相同。
源码、原始字节、全部指标和判定已由另一个进程独立读回。
“独立读回”指对同一组原件的核验，统计意义上的 `independent_confirmation` 仍为 false。

数据角色固定为 `DISCLOSED_DEVELOPMENT_DIAGNOSTIC_NOT_HOLDOUT`：两个已披露材料对与三个相关事件，
沿用 post-BF 单声道、给定方向和精确参考同步、合成线性回声路径及量化 S16 近端参考。主比较只有一个独特条件，另外两个 p1 场景的共同前缀和主窗口输出完全相同，
只承担一致性检查，不构成三个独立复现。结果不能代表新材料、新房间、真实阵列、SSC305 实机或产品效果。
tap 与 final 之间涉及输出选择、抑制、舒适噪声和量化等联合路径，本实验不能单独识别 RES 的因果贡献。
