## Immutable byte-level procedure / 字节完整性实验

1. Re-download **one and only one** pinned Gym RAR on a hosted GitHub runner, maximum 512 MiB / 13 minutes, and rehash its original bytes before inventory or extraction. No source fallback, token, paid service, repaired CSV, additional scene or cached sound.
2. Reuse existing first-party S2 fixed lexical selection of **one static and one moving** full quartet, the original physical **CH1/CH3/CH5/CH7** in each group. Require the complete RAR inventory name hash and exact eight member-path SHA values, original byte count and each FLAC SHA256 to match the sealed S2 snapshot **before each decoder invocation**; no alternative utterance or channel if an original mismatches.
3. Use the original S2 bounded single-member 7z streaming extraction (32 MiB/member, 128 MiB combined compressed FLAC *file* bytes, 75 sec each, 180 sec extraction). Native headers must exactly match original S2 STREAMINFO, including original **mono, 48,000 Hz, 16-bit, nonzero PCM MD5** and total samples: 238895 for each static channel, 237071 for each moving channel. No resampling, repair or reordering.
4. Only a **preinstalled and SHA/version-provenanced** trusted native FLAC CLI is permitted: prefer system \`flac --decode --stdout --force-raw-format --endian=little --sign=signed\`; if that binary is absent, allow the already preinstalled \`ffmpeg -hide_banner -loglevel error -nostdin -i <original-FLAC> -map 0:a:0 -c:a pcm_s16le -f s16le pipe:1\` solely when all eight originally declared STREAMINFO MD5 values match the decoded S16LE exactly. No \`-ar\`, \`-ac\`, filter, trim, external install or weaker raw contract is allowed. This preinstalled-equivalent path was explicitly allowed by preregistration #707; first actual hosted #708 source probe without preinstalled \`flac\` failed closed and was preserved as Artifact 11672454320. Each original file is decoded once into an in-memory **constant-size streaming hash**, never written as raw PCM. The output must be exactly **477790 bytes** (static) or **474142 bytes** (moving), with <=30 s per file and <=180 s total PCM verification. Calculate decoded signed S16LE MD5 and SHA256 and compare **its MD5 exactly to the frozen original nonzero STREAMINFO MD5**. Any mismatch, unsupported decoder flags or timeout fails closed; never skip a channel, change thresholds or reinterpret MD5.
5. An **independent verify step** on the same ephemeral runner separately rereads and rehashes the entire original RAR, 8 selected original FLAC files, validates their complete headers and reruns the *same eight decoded byte checks*. Compare independently reconstructed rows, exact decoder version+binary SHA, selection and identity to the canonical receipt.
6. Delete the original RAR/FLAC from isolated \`$RUNNER_TEMP\` **before** public Artifact upload. Retain only canonical \`receipt.json\`, \`collect.log\`, \`verify.log\` and \`SHA256SUMS\` for 30 days, without PCM/RAR/FLAC, input frames or original source CSV. A failure is a preserved explicit \`REALMAN_D2_S3_GYM_PCM_BYTES_NOT_ADMITTED\` decision and job failure; never fabricate a success.

Only all **8/8** independently verified, hash-matched original files can admit \`REALMAN_D2_S3_GYM_8_PCM_MD5_VERIFIED_RESEARCH_ONLY\`. Both positive and failure receipts keep \`shipping_authority=false\`, \`doa_accuracy_measured=false\`, \`captured_four_mic_sync_verified=false\`, \`camera_audio_timebase_verified=false\`, and \`original_d1_csv_source_admitted=false\`.

## Explicit nonclaims / 不得扩大解释

PCM-MD5 PASS means codec-level original-source decoded bytes agree with original FLAC STREAMINFO. It **does not** prove four physical microphones have matched sample-zero timestamps, synchronized capture/AV clock, correct geometric calibration or source-angle labels, GCC-PHAT/SRP-PHAT DOA error, beamformer array gain, AEC/NS quality, real SSC305 CPU/RAM/p99/latency, E001 product HIL or any commercial redistribution/shipping authority. A future acoustic or clock study must be independently preregistered and keep development versus untouched holdout separate. The frozen I025–I040 NS lineage and all shipping C are unchanged.
