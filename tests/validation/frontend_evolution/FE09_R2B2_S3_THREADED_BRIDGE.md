## Runtime architecture / 运行时

- Reuses **unchanged protected S1** `fe09_b2s1_private_queue.[ch]` (C11 SPSC capture and independent render with acquire/release, first-party 16/32/48→16k N SRC and FIR33 BF) and **unchanged protected S2** `fe09_b2s2_private_apd.[ch]` (experimental little-endian APX3 128-byte header/CRC, bounded 128 frames/1MiB, optional reference, strict source/epoch, unknown timestamps). The two frozen projects' source Git blobs are rechecked against the qualified protected predecessor on every run.
- T0 adds one **test-only** `fe09_b2s3_private_bridge.h/.c`. Its worker serially owns the S2 writer and the S1 consume interface. It first calls the actual S2 writer in a caller-owned **separate shadow arena**; only after the record has been fully validated and serialized does it try `fe_b2s1_process_one` on the published capture/render S1 frame pair. On `EEMPTY` / `EMISMATCH` / any other S1 error the retained APX3 writer and caller outputs remain uncommitted. On success a proven-size record is copied to the real writer and the source success counter advanced. There is no heap, mutex, file I/O or blocking wait inside `fe_s3_bridge_step` itself.
- The actual test runs **two independent pthread producers** (physical microphone and optional render) and a separate DSP consumer. Each producer writes one bounded retained raw-PCM mirror slot, publishes it through the frozen S1 SPSC API and a separate release/acquire completion counter; worker waits for both to be published **outside** the processing API, consumes a matched pair, emits the shadow-first APX3 record and compares BF+render outputs bytewise to a second original first-party SRC+FIR33 instance on the **same ISA**. A worker release acknowledgment prevents a producer overwriting the bounded mirror until both DSP and recording have completed. Test-only `sched_yield` occurs outside frame processing.
- 48 deterministic profile combinations: C1 baseline, C2 ULA, C4 ULA, C4 UCA × 16/32/48k × render 0/1 × SPSC depth 2/4; 100 accepted 10ms frames each (4,800 hosted frames per ISA), **actual 3 threads whenever render=1**. APX3 is decoded/replayed byte-for-byte to original retained synthetic PCM for all fixed profiles. Use source gaps, render-only gap, full clock reset and separate XRUN; no fabricated render PCM or physical ADC/DAC timestamp. Only cross-ISA APX3 integer little-endian wire bytes are compared exactly; **Float32 BF outputs are only compared within the same target**.
- A separate **native hosted** representative 100,000-frame sustained C1/16kHz + independent render three-thread S1 stress reuses a bounded ring, but does *not* produce a 100k-frame APX3 archive, which would violate the S2 128-frame bound. The 100-frame APX3 profiles prove bounded recording; continuous archival/chunk rotation must be a separately admitted contract before product use.
- A distinct quiescent adversarial fixture injects 96 malformed source/flag/epoch/count variants, missing frames, mismatched capture/render sequence and incomplete recorder. No retained APX3 frame is committed on rejection, then **a full source-owner stop-and-reinit** demonstrates a *nonseamless* recovery requiring loss of prior BF histories. It is not permitted to pretend that render-only resynchronization is seamless or that sequence pairing proves shared ADC/DAC clocks.

## Known limits / 尚未闭环

1. **Mismatch liveness:** an S1 `EMISMATCH` leaves both queue tails in place by design. The T0 only proves detection, recorder noncommit, and caller-controlled **full quiescent re-init**. A runtime requiring render-only recovery **without resetting capture/BF** needs an independently source-reviewed bounded authority mechanism, and cannot be marked qualified merely because T0's normal matching pairs pass.
2. **Index wrap and scheduler:** the 100k stress begins from zero; it is **not** a test of the ring counters near `UINT32_MAX`. Add actual near-wrap producer/worker interleaving proof to S3 before full stage closure, without modifying frozen S1 source semantics or fabricating clocks. Current caller ownership makes metrics (`fe_b2s1_get_info`) **quiescent-only**. No concurrent 64-bit non-atomic metrics polling.
3. **Resource delivery:** the hosted scratch includes a full 1MiB S2 preflight shadow plus 1MiB archive, separate S1 work/snapshot, direct BF oracle buffers and three thread stacks. It is intentionally **not** an SSC305 product-memory-optimized worker, **not** a full C4 192KiB or physical 10ms p99 certificate. Measured hosted p95/p99 in stderr are descriptive only.
4. **License/product:** all PCM is deterministic first-party synthetic, no paid service, no private recordings. No installed 3.x/public ABI, audio scoring search, actual geometry/calibration or acoustic gain, physical capture/render drift, production `src/`, public `include/`, CMake, release tags, legacy APD2 reader, real full-duplex AEC, SSC305/HIL/E001 or Product Certification edits or claims.
