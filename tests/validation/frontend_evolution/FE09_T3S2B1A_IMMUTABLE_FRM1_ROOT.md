## Scope and frozen original bytes / 源代码、字节与线程所有权

Noninstalled **POSIX hosted research** stage only. The actual source chain remains first-party S2 one-frame original **APX3**, first-party `fe_s2_writer_begin/append/finish/decode/replay` and original CRC, actual T3-S1 pinned capture/optional source-owned Render drain, actual T3-S2-A file and full original 200-byte FBS1, original T3-S2-B0 private 160-byte FRM1 header plus N×original unmodified full FBS1 rows. B1a does NOT redefine APX3, modify the source BF worker, publish SDK/include/CMake or alter I025–I040. All upstream source+own files carry SHA256 pins against immutable protected predecessor main.

Outer root files are stored in a **separate trusted owner-exclusive POSIX directory**, NOT inside S2-A's source file directory, preventing root names from being misread as original APX3. The caller passes a directory FD; inspect owner uid, group/other write permissions and dev+inode on every call. `fe_t3s2b1a_bind` opens a fresh independent directory FD for every inventory, avoiding shared readdir offsets. Every canonical root name includes original generation, global sequence and SHA256 of complete B0 FRM1 bytes. Only lowercase canonical hex and fixed ASCII filename are accepted. Reject foreign files, symlinks, hardlink aliases, sparse/gapped sequences, invalid generation, extra digest at same sequence, orphan partial files or source directory overlap. Caller does not grant shared-writer semantics.

## Exact hosted transaction ordering / 不覆盖提交、恢复与写盘顺序

1. Before commit, **reconstruct the complete B0 FRM1 bytes FROM ORIGINAL ALREADY PUBLISHED S2-A SOURCE FILES**, for 1..N global Capture sequences; do not merely trust a previously computed in-memory root. For each file reopen with `O_NOFOLLOW`, verify regular single-linked exact-length file, recover original 200-byte FBS1 plus raw original APX3, and invoke unchanged first-party B0 `fe_t3s2b0_observe_acked` for original S2/APX3 CRC, `fe_s2_replay` PCM/FNV witness, source identity, canonical previous-full-row SHA chain and exact byte accounting. A replay witness is clearly NOT a manufactured live BF/S1 ACK.
2. The caller B0 index must **byte-for-byte equal** the rederived FRM1, bound to the exact pinned source and complete original 1..N sequence. A source input can be at most one frame beyond the last committed index root, so an interrupted S2-A ACK/index update remains visible as an explicit unrooted pending frame. Never silently fast-forward, skip Render absence, assume real ADC/DAC time or invent a source epoch.
3. Index publication is outside BF/audio threads: `O_EXCL|O_NOFOLLOW` temporary exact-length FRM1 write, `fsync(file)`, POSIX `linkat` atomic **no-replace** immutable final basename, unlink temporary, `fsync(root_directory)`, `O_NOFOLLOW` reopen and full byte+source digest re-read. A matching preexisting complete immutable root is idempotently admitted only after the independent full source verification and directory synchronization; conflicting root is a hard failure.
4. Failure after final hardlink publication may leave both canonical root and `.part` with the SAME inode; restart verifies the actual original file+FRM1 and permits unlinking only this verified duplicate link, followed by directory fsync. Unpublished `.part` alone, truncated root, unknown file, source mismatch, missing APX3, invalid root hash, short I/O, file or directory sync failure remain fail-closed. A physical root may already be visible after a failed callback; B1a does NOT retroactively change the original source ACK and explicitly requires rebind/idempotent recovery.
5. Retain immutable root snapshots for each global Capture high-water from 1 to <=16, without overwriting or removing any original record or older root. The immutable root chain is checked against independently reread original S2-A data at each restart. A new root cannot be accepted with a missing prior root; after capacity is full, return FULL/prevent new B0 ACK, not hidden source loss. No manifest left-anchor pruning or physical filename modulo reuse in B1a.
