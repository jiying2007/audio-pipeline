# FE-C2-FIXED-DIRECTION-HEALTH-V1：实施冻结记录

日期：2026-11-06。状态：实施和测试前冻结；本文件不记录候选结果。

本记录细化 `DUALMIC_INTERACTION_INTERCOM_V1_PLAN.zh-CN.md` 的 B 工作包，不修改原计划。原始算法基线为 `438fe09d79ff768306c00573849517bcd91cbc6e`；共同合同提交为 `6056682486c1a2a2c84d77135de8118e07fc8cf3`。只允许一个固定方向健康候选，不做阈值、种子或场景搜索。结果另存，失败保留。

## 固定实现边界

- `track_direction=true` 原分支、全部原阈值、方向搜索/平滑、更新节拍和输出公式保持。始终跟踪的基线对照须逐字节比较 PCM 及原 176 B BF 状态，不含新增字段。
- `track_direction=false` 每四帧在实际输出使用的固定 lag 做一次 O(n) 观察，不搜索其他 lag，不写 `lag`、`lag_score`、`score_updates` 或原 `counter`。
- 只追加一个 `uint32_t fixed_health_counter`，初始化为 3。既有确认计数、恢复计数、目标通道与 fallback lag 复用，不增 PCM 缓冲、不分配、不阻塞、不做 I/O。常规 32 位标量 ABI 下 BF 私有状态预期 176→180 B，standalone module 184→188 B；必须实测，整条 pipeline 的对齐增量另报。
- 观察的 `aa/bb/xy` 用与旧 lag 观察相同的隔点采样和因果历史，使用实际固定 lag；roughness 复用旧计算。两通道观察均方能量必须严格大于 `(1/32768)^2`，即 normalized S16 的 1 LSB RMS；正则项不算有效信号。此下限只确定观察资格，不是声学 VAD。
- hard signature 保持原数值：coherence < 0.980，幅度比 < 0.45 且严格介于 0.08 与 0.28，强通道 roughness < 0.18 × 弱通道 roughness。不放宽规则、不创建新的 soft fallback。
- 连续两次有效观察必须支持同一个较弱目标通道才进入 hard fallback；目标变更重新从一次累计。帧对齐、持续满足条件的输入须在最多八个完整 10 ms 帧内进入。
- hard 恢复保持原数值：幅度比 > 0.52，强通道 roughness > 0.60 × 弱通道 roughness；连续八次有效观察才退出。持续正常输入须在最多 32 个完整 10 ms 帧内退出。
- 静音、低于观察资格或非有限观察不累计确认/恢复；清连续计数，但保留已确认 hard 路由。有限正常输入输出必须完整、有限。
- 进入固定模式时保留已确认 hard 状态及固定 lag；未确认 soft fallback 撤销并回固定混合。回跟踪模式由原更新逻辑接续，不因模式切换无条件清 hard。
- 本轮不添加 crossfade，不调整原单通道/等权输出增益。记录故障与恢复、模式切换的电平和采样边界，不从有限输出或完整帧宣称无点击。
- 单路精确零、断流、rail/stuck、普遍削波和反相不新增分类；若未满足既有 signature，保留原固定混合。SAFE 仍旁路 BF 使用 mic0，不宣称本改动保护 SAFE。

## 先固定数据和测量角色

仅使用本仓第一方、可重建合成工程信号。所有数据均为已曝光的开发/回归角色，不是独立确认、真人语音、中文 KWS 或 SSC305 物理证据。无外部下载，无盲集选择，无训练。

- 采样率：8000、16000 Hz；帧长分别为 80、160，10 ms。
- 几何：70 mm 双麦；固定方向原 lag 为 0，另检查预置 +1/-1 lag 的不变性及合法离轴正/负时延。
- clean：绝对样点时间上的三正弦之和，1400/2100/3200 Hz，幅度分别为 0.045/0.020/0.010；相位为 0，连续跨帧生成。
- hard 输入：一通道为 `0.24*sin(2*pi*120*t) + 0.05*clean`，另一通道为 clean；左右分别执行。HPF 使用当前实现的原 80 Hz 状态。
- 噪声：固定 xorshift32，种子 `0x6d2b79f5` 与 `0x13579bdf` 分别给两个通道，不挑选种子；固定振幅 0.06。没有按结果更换 seed。
- 普通幅度负例：1.0、0.75；合法弱通道负例：0.25、0.10，左右互换。离轴和转向采用 8k 下 -1/0/+1、16k 下 -3/0/+3 的输入时延；不是 DOA 准确率测量。
- 静音负例：双路精确零，以及把 hard 波形整体缩小到任一通道峰值不超过 0.5 LSB 的低幅输入。另检查 1 LSB RMS 资格边界；边界只是数值测试。
- 未覆盖故障负例：单路零、单路 +0.95 常量、两路反相。记录未分类/原混合行为，不将其命名为通用坏麦恢复。

## 固定测试矩阵与判据

1. 两采样率、左右 hard 输入、BF-only 与 HPF→BF：首次确认、目标一致性、≤8 帧进入、可信单通道输出、≥8 次有效观察后且≤32 帧恢复。所有固定运行中 lag、scores、score_updates、旧 counter 不变。
2. 两采样率健康同相、轻微增益差、合法弱通道、合法离轴、连续转向、普通独立噪声、静音、单零/rail/反相负例：新固定 hard 不误触发；健康输出逐样本等于原固定 lag 的等权公式。对未覆盖故障只验证约定的这些特定工程输入。
3. 一次候选不足、左右候选交替不得累积；恢复第七次后插入静音或不满足恢复的一次须重新累计。静音期间保留已确认 hard 状态，输出不造声。
4. 真跟踪进入 hard 后切固定、固定 hard 后切真跟踪、soft→固定、reset，以及公共 pipeline FULL/LITE/SAFE 切换：明确状态生命周期，完整有限帧，无方向状态意外更新。
5. `AP_BUILD_BF_DIRECTION_TRACKING=0` 的 standalone 非零 track 请求保持 AP_ESTATE，模块状态和输出原子不变；false 可用。既有模块/合约/实时测试继续执行。
6. 使用相同预定输入，对精确 base 与候选独立编译运行始终 `track=true` 的健康、hard、恢复、离轴、转向、噪声与静音序列；输出原始字节与旧状态字段字节必须完全相同。该比较不是声学优胜判定。
7. 新健康测试先在旧 BF 上执行，须实际暴露 fixed hard 不进入或模式切换丢状态，再运行候选；不能用编译失败或新字段缺失充当基线缺陷证据。
8. 实测 BF/module/pipeline state，检查零新增数据面堆分配、既有状态/ROM上限；默认和 tracking-OFF 构建与 sanitizer 定向执行。每次本地构建/定向测试上限 300 秒。SSC305 物理耗时、KWS FAR/FRR、对讲主观效果均记 NOT_RUN。
